# Konvoj

Közös autózás app: 3D térkép és útvonal, saját sebességmérő, mérőpont-jelzés, csapat, üzenetek, adó-vevő, közös úti cél, megállás-szavazás, benzinpénz-elosztó, talik, törzshelyek, parkolóhelyek, autó-dosszié, tankolási napló, pihenő-emlékeztető.

A csapat funkcióhoz: Firebase Realtime Database, `firebase-rules.json` szabályok, `DB_URL` az `index.html`-ben.

Fix traffipaxok adatai: police.hu, a traffipax-ma.hu exportján keresztül (letöltve: 2026-11-25).
