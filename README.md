# Konvoj

Közös autózás app: 3D térkép és útvonal, saját sebességmérő, mérőpont-jelzés, csapat, üzenetek, adó-vevő, közös úti cél, megállás-szavazás, benzinpénz-elosztó, talik, törzshelyek, parkolóhelyek, autó-dosszié, tankolási napló, pihenő-emlékeztető, témák, autó ikonok és profil, vezetés mód, fekvő nézet, kedvenc helyek, megállók és útvonal-alternatívák, jelentések, kutak és töltők, időjárás a célnál (Open-Meteo.com), házak: OpenStreetMap és Overture Maps (ODbL), nyilvános „Mindenki” mód (első megnyitáskor egy koppintással kapcsolható be; úton, 5 km-en belül), otthon megosztása a csapattal, „Kint vagyok” jelzés, autós kártya fotóval, megosztható napi összefoglaló, törzshely fotófal, QR-meghívó, SOS, láthatatlan mód.

A csapat funkcióhoz: Firebase Realtime Database, `firebase-rules.json` szabályok, `DB_URL` az `index.html`-ben.

Fix traffipaxok adatai: police.hu, a traffipax-ma.hu exportján keresztül (letöltve: 2026-11-25).
